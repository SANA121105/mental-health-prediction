# mental-health-prediction

## Objective

To predict student mental health risks using machine learning.

## Dataset

This project uses a publicly available dataset from Kaggle.

## Features

Includes lifestyle and academic factors like sleep, study hours, stress, and social interaction.

## Model Used

Random Forest Classifier

## Result

The model predicts mental health risk levels with good accuracy.

## Conclusion

This system can help identify students at risk and enable early intervention.
